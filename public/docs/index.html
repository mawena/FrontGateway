Introduction

Base URL: http://pecorator.ulrich.client

This documentation aims to provide all the information you need to work with our API.

As you scroll, you'll see code examples for working with the API in different programming languages in the dark area to the right (or as part of the content on mobile). You can switch the language used with the tabs at the top right (or from the nav menu at the top left on mobile).

Authenticating requests

To authenticate requests, include an Authorization header with the value "Bearer 1|3EHtZpCFL35Mn1tff8F1JxPhNTfCsxNveKXdC652a8400aed".

All authenticated endpoints are marked with a requires authentication badge in the documentation below.

You can retrieve your token by visiting your dashboard and clicking Generate API token.

Authentification

EndPoints pour gérer l'authentification

Connecte un utilisateur

requires authentication

Example request:
curl --request POST \
    "http://pecorator.ulrich.client/api/auth/login" \
    --header "Authorization: Bearer 1|3EHtZpCFL35Mn1tff8F1JxPhNTfCsxNveKXdC652a8400aed" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json" \
    --data "{
    \"email\": \"admin@pecorator.com\",
    \"password\": \"azerty\"
}"

const url = new URL(
    "http://pecorator.ulrich.client/api/auth/login"
);

const headers = {
    "Authorization": "Bearer 1|3EHtZpCFL35Mn1tff8F1JxPhNTfCsxNveKXdC652a8400aed",
    "Content-Type": "application/json",
    "Accept": "application/json",
};

let body = {
    "email": "admin@pecorator.com",
    "password": "azerty"
};

fetch(url, {
    method: "POST",
    headers,
    body: JSON.stringify(body),
